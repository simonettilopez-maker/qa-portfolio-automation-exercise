# 🧪 Proyecto QA: Ejecución de Testing, Análisis y Registro de Errores - Automation Exercise

Este repositorio contiene la documentación y evidencias correspondientes a las **Prácticas Profesionalizantes del Voluntariado Teclab**. El objetivo principal consistió en la **ejecución de testing sobre un proyecto real, análisis de resultados, detección y registro de errores y propuesta de soluciones** sobre la plataforma **Automation Exercise**.

## 📌 Alcance del Trabajo Realizado

1. **Análisis y Ejecución de Pruebas:**
   - Matriz de casos de prueba diseñados en sintaxis **BDD / Gherkin** (`01-documentation/`).
   - Pruebas de integración de API con **Postman** (`02-api-testing/`).
   - Verificación de persistencia de datos mediante consultas **SQL** (`03-database-sql/`).
   - Automatización del flujo principal de autenticación con **Playwright** (`04-automation-playwright/`).

2. **Detección, Registro y Soluciones:**
   - **Informe de Bug Report (`TC-005`):** Documentación detallada sobre la vulnerabilidad/falla detectada en el campo *Name* (falta de sanitización).
   - **Propuesta de Soluciones:** Propuestas de sanitización de inputs a nivel frontend/backend y consultas SQL de auditoría.

## 🛠️ Herramientas Utilizadas
- **Gestión:** Trello (Tablero Kanban).
- **Diseño de Pruebas:** MS Excel / Word, BDD Gherkin.
- **API & BD:** Postman, SQL.
- **Automation:** Playwright (JavaScript).
