Proyecto de Voluntariado Profesional - QA & Testing (Teclab)

Repositorio oficial para la validación, diseño y automatización de pruebas sobre la plataforma **Automation Exercise**.
---
Estructura del Repositorio
01-documentation/: Contiene el informe final en formato Word y PDF (PROYECTO DE VOLUNTARIADO PROFESIONAL.docx / .pdf) con las Historias de Usuario (US-001 a US-004) y la matriz de casos de prueba (TC-001 a TC-005).

02-automation/: Scripts de automatización en Playwright (login.spec.js).

03-api-sql/: Consultas de validación en base de datos (database_queries.sql) y colección de pruebas de API en Postman.

04-metrics-reports/: Reportes de errores, hallazgos de QA (como la falta de sanitización en el campo Name - TC-005) y métricas de ejecución.

Tecnologías y Herramientas Utilizadas
Gestión y Pruebas Manuales: Trello (Metodología Kanban), Excel.

Automatización Web: Playwright (JavaScript / Node.js).

Pruebas de Backend: Postman (API Testing).

Base de Datos: Consultas SQL para trazabilidad de registros.

Desarrollado como parte del Voluntariado Profesional de QA en Teclab.
